# 🐳 Jakarta EE Docker Labs (Базовая платформа для лабораторных)

Привет 👋

Этот репозиторий --- **базовая инфраструктурная платформа** для
выполнения лабораторных работ.

Он уже содержит:

-   🐳 Docker
-   🌐 GlassFish 8
-   🗄 PostgreSQL (если используется)
-   ⚙ Настроенную среду
-   📦 Базовый пример приложения

Вам НЕ нужно настраивать Java, сервер или БД вручную.

------------------------------------------------------------------------

# 📌 Как работать с этим репозиторием

## 1️⃣ Клонируем проект

``` bash
git clone https://github.com/AngryDivan/jakarta-ee-docker-labs.git
cd jakarta-ee-docker-labs
```

## 2️⃣ Запускаем
# ВАЖНО!!! Перед запуском команды снизу не забудьте включить Docker Engine(просто запустите Docker Desktop) и любой сервис на три буквы(подгрузка glassfish у вас просто выдаст ошибку).

``` bash
docker compose up --build
```

# После запуска:

GlassFish Admin Console:\
http://localhost:4848

Демо-приложение:\
http://localhost:8080

Если у вас это запустилось без ошибок - значит все работает.

# 🎯 Как выполнять лабораторные?

## 🥇 Рекомендуемый вариант (самый правильный)

Оставить этот репозиторий как **базовую платформу**, а лабораторные
делать как отдельные модули внутри него.

То есть:

    jakarta-ee-docker-labs/
    │
    ├── server/          ← основной backend
    ├── fx-client/       ← JavaFX клиент
    ├── labs/
    │   ├── lab1/
    │   ├── lab2/
    │   ├── lab3/
    │   └── ...

Каждая лабораторная:

-   это отдельный Maven module
-   собирается как отдельный WAR или JAR
-   деплоится в уже настроенный GlassFish

------------------------------------------------------------------------

# 🧱 Как создавать новую лабораторную

## 🔹 Шаг 1. Создать Maven module

В папке:

    labs/

Создать новый модуль, например:

    lab1/

Он будет отдельным проектом (своим pom.xml).

------------------------------------------------------------------------

## 🔹 Шаг 2. Тип лабораторной

### Если это JavaFX

Работаем в:

    fx-client/

или создаём отдельный fx-модуль в labs.

------------------------------------------------------------------------

### Если это JSF / Jakarta EE

Создаём WAR внутри:

    labs/labX/

------------------------------------------------------------------------

## 🔹 Шаг 3. Сборка

После добавления лабораторной:

``` bash
docker compose up --build
```

------------------------------------------------------------------------

# 💡 Логика работы

# ❗ Частые проблемы

## Порт 8080 занят

Закройте другое приложение, которое его использует.
